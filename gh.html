Cheat sheet

GitHub CLI

Commands for the gh CLI. In the codespace section, cs is the built-in alias for codespace. The stack section needs the gh-stack extension.

Codespaces

gh codespace commands
Action Command
List your codespaces gh cs list
Open one in VS Code no name given, it asks which one gh cs code
Stop it gh cs stop

Stacked PRs

gh stack commands
Action Command
Start a stack from an existing branch adopts the branch and its open PR gh stack init --base <trunk> <branch>
Add a branch on top run from the top branch; checks it out gh stack add <new-branch>

Reference: the gh codespace manual and the gh-stack repo.
